Component one — where

Towns sorted by how far away they are, not A to Z.

The Place menu is alphabetical today, so Aireys Inlet leads and Jan Juc sits in the middle. Alphabetical is an ordering that carries no information about a coastline. Sorting by distance makes the list itself a map: Jan Juc, Torquay, Bells Beach, Bellbrae, Point Addis — you can read the drive down the column.

Buildable now

The dial does what km could not

Distance is a haversine from the pin, computed at render — 975 rows answer it. The km column would have managed 294.

Note what the dial does at the bottom of its range: at 1 km you get Jan Juc and almost nothing else, which is the honest answer for a village. The control should not pretend there is a rich 1 km radius here.

Needs a decision

223 rows have nowhere to be

Any distance filter has to decide what to do with a row that carries no coordinate — 48 are "Surf Coast wide", 22 are at Home, and the rest are ideas and groups with no premises.

The studio drops them as soon as you move the dial off maximum, and says so under the count. Silently excluding them is the trap: a filter that quietly returns less than the world contains is the failure CLAUDE.md already records three times.

Open question

Home is not always Jan Juc

Every distance in the database is measured from one point because the project was built for one household. The moment a second person in Ocean Grove uses this, the dial is measuring from the wrong place.

The fix is small and worth doing early: let the reader set the origin — a town from this very list — and keep it in localStorage beside notice.saved. Nothing in the schema changes, because the distance was never stored.

Component two — what

Nine groups you can see, forty-four types you have to ask for.

The board hides both behind dropdowns. Nine things is not a dropdown — it is a band, and putting it on the surface is what teaches a first-time reader the shape of the site before they touch anything. Forty-four types genuinely is a menu, and it should stay one.

Already the rule

The menu leaves out what it cannot offer

Pick The ocean and the type chips become that group's five and nothing else — beach, surfing, swimming, water, paddling. Pick The community and you get six, led by kids 111 and reading 101.

Watch the counts as you move the dial too: types whose last row falls outside the radius disappear rather than sitting there greyed at zero. That is the documented behaviour, and it is the reason 44 types stay usable.

Worth noticing

The community group is a fifth of everything

280 rows, and 212 of them are kids and reading — which is the library import wearing its types. The Ocean, the thing this coast is actually known for, is 104.

A group band with honest counts makes that imbalance visible on the homepage rather than buried in a dropdown. It is not a bug to fix in the interface; it is a research backlog the interface should keep pointing at.

Free

The icons already carry the colour

Each type's Lucide glyph is tinted by its group's hue, so a list scanned quickly reads as bands of colour before any word is read — the same wheel the board already uses for the row hover tint.

One caution from the sprite: cycling and mountain biking share the bike deliberately, so 44 types map to 43 symbols. Any check that asserts a one-to-one mapping will report a false gap.

Component three — the map

Rings, not boundaries.

The vision takes a position — organised by radius and by interest, never by jurisdiction — and a map is where that position either shows or doesn't. So the map draws no council lines, no shire, no region. It draws distance rings from home and the listings themselves.

The good bit

The database draws its own coastline

There is no basemap in the studio above and it still reads as this coast, because listings follow settlement: the pins trace the Surf Coast, curl around the Bellarine and clot at Geelong entirely on their own.

Worth knowing on a homepage: a small map does not need tiles to be legible. Tiles cost a network dependency and a third party; a pin cloud costs nothing and cannot fail to load.

Honest limit

This is not MapLibre

The real map uses MapLibre 5.24.0 with CARTO tiles and must keep doing so — you need pan, zoom and a real basemap to actually navigate. A published artifact cannot load either, its CSP blocks every external host.

So read the map above as a homepage map: a fixed, glanceable one that answers "where is all this" in one look and hands you to the real map when you press it.

Standing count

Say what is not on it

975 of 1,198 are pinned. The board already prints the gap under its map and this keeps that promise — a map quietly showing four fifths of the database is a map that lies.

And the 975 pins sit on only 531 distinct coordinates — 93 of them shared. That is correct, not duplication: an event inherits its venue's pin, so The Dome carries 61 listings on one dot and the Armstrong Creek library 41.

Which is the real lesson for a map of this database — it is a map of venues, not of the region. So a mark is sized by how many listings stand on it. Draw them all the same and Geelong's library reads exactly like a lookout with one row.

Component four — the brand block

The homepage has to say what this is, once, near the bottom.

Not a mission statement at the top — a person who arrived wanting to know what is on this Saturday should get that first. But a commons has to state its terms somewhere, and the foot of the homepage is where a reader who is still scrolling has actually asked.

Recommendation

Spend the only "we" here

§9 leaves the voice unresolved between the impersonal register and the first person. The impersonal one is right nearly everywhere — a bench has no first person, and every line that survived several drafts is stated rather than pitched.

But we want to write it down is the one place the people making this admit to existing, and a commons that never says "we" is asking for contributions from nobody in particular. Spend it once, at the bottom, and keep every other line impersonal.

Why the refusals

The four "will nots" are the brand

The About page already carries them and they are the most distinctive writing the project has. Most listings sites would never print them, because most listings sites do guess.

Putting them on the homepage as a component — each with its live number underneath — turns a policy into evidence. 223 honestly blank is a stronger claim than any adjective, and it updates itself.

If you built one thing next
Organised by radius and by interest, never by jurisdiction. NOTICE_VISION_NOTES.md, §3 — the position this all serves

The group band. It is free — GROUP_OF already derives it, nothing is stored, nothing can go stale — it puts the interest axis on the surface where §4 says it belongs, and it is the one control that makes the site legible in a single glance to somebody who has never seen it. The dial is second, and it needs the settable origin before a second household uses it.
